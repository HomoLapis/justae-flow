Suggested layout, one folder per example:

```
examples/
  01-storyboard-series/      the EffectCraft project, its .shiftfield.json and a render of the cut
  02-placeholder-fill/       before/after frames of a placeholder filled in place
  03-upscale-on-layer/       source clip and the SeedVR2 ×2 result laid over it

```

Each version Shiftfield generates comes with a `.job.json` (workflow, template, prompt, seed, models, timings) —
keep it next to the media so anyone can reproduce the result.
